PART 10 — TEXT CONTRAST REQUIREMENTS
==================================================

Use WCAG 2.2 AA as the accessibility reference.

Requirements:

- Normal text: minimum contrast ratio 4.5:1.
- Large text: minimum contrast ratio 3:1.
- Meaningful UI control boundaries and indicators: minimum contrast ratio 3:1 against adjacent colours where applicable.

Do not assume that white text is automatically readable if placed on an incorrectly layered background.

Inspect actual foreground/background combinations.

Pay attention to opacity inheritance.

A white text element inside a parent with low opacity can become unreadable.

Avoid applying opacity to entire text containers merely to produce muted text.

Use explicit muted colour variables instead.

Ensure:
- Placeholder text remains readable.
- Secondary text remains visible.
- Disabled text is distinguishable.
- Chart legends are readable.
- Icons are visible.
- Borders remain distinguishable.
- Focus indicators are obvious.

Where the reference's muted grey does not meet the required contrast for a particular surface, select a sufficiently lighter equivalent for that surface without changing the overall visual identity.
